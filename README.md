
# Singleton 패턴 구현

## 1. 프로젝트 소개
Python을 사용하여 Singleton 디자인 패턴을 구현한 프로젝트이다.
Singleton 패턴은 클래스의 인스턴스를 하나만 생성하고, 여러 변수가 동일한 인스턴스를 공유하도록 하는 디자인 패턴이다.

## 2. 실행 환경
- 사용 언어: Python
- Python 버전: 3.13.14
- 실행 환경: Windows
- 실행 파일: main.py

## 3. 실행 방법
터미널에서 main.py 파일이 있는 폴더로 이동한 후 다음 명령어를 실행한다.

```bash
py main.py
```

## 4. 실행 결과

```text
동일 인스턴스 확인: True
a의 count: 10
b의 count: 10
직접 생성 시 동일 인스턴스: True
```

## 5. Singleton 패턴 설명
Singleton 클래스는 `__instance`라는 클래스 변수에 생성된 인스턴스를 저장한다.
`__new__()` 메서드에서 인스턴스가 이미 존재하는지 확인하고, 존재하면 새로운 객체를 만들지 않고 기존 객체를 반환한다.
`a is b`의 실행 결과가 `True`이므로 두 변수가 동일한 인스턴스를 참조한다는 것을 확인할 수 있다.
또한 `a.count`를 10으로 변경했을 때 `b.count`도 10으로 출력되어 두 변수가 상태를 공유한다는 것을 확인했다.
